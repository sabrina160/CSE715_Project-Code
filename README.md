# Multi-modal Beta-VAEs for Uncovering the Latent Structure of Music through Disentangled Representation and Interpretable Clustering
This project implements a progressive Variational Autoencoder (VAE) framework for uncovering latent structures in large-scale music data using audio features, lyrics, and genre information.

The goal is to learn disentangled, interpretable representations that improve clustering quality in multi-modal music datasets.
